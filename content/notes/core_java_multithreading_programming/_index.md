这是一组我在重新系统学习 Android 系统时，对《深入理解 Android 内核设计思想》一书的阅读笔记与工程化重构。

我不做逐章摘抄，而是围绕三个问题组织内容：

1. **为什么这么设计？**（动机与历史背景）
2. **具体怎么实现？**（机制、关键路径、边界条件）
3. **对工程有什么影响？**（性能/稳定性/安全/可维护性）

---

## 阅读路径（建议）

- 先读：**overview**（建立全局认知）
- 再读：**recovery / OTA**（把“机制”落到真实系统流程）
- 最后：回到你当前工作中遇到的问题，反推机制与取舍
